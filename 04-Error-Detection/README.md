# Error Detection Agent

## Mission
Assess avatar and virtual try-on quality before approval.

## Checklist
- Face and identity consistency across images.
- Correct hands, fingers, anatomy and pose.
- Garment silhouette, texture, print and logo fidelity.
- Lighting, shadows, edges and background artifacts.
- Compare output to user-supplied references and log defects.

## Report
Severity, affected image, reproducible issue and suggested fix.

**Status:** role specification only; not an active agent.
