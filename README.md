# VELORA Avatar AI

Free-first avatar creation and virtual try-on research project, coordinated through four defined agent roles.

## Agent roles
1. CEO: plans and reviews work; requests human approval before publishing or spending.
2. Avatar Production: designs prompts, avatars and garment try-on workflows.
3. Security: reviews privacy, dependencies, repository licenses and commercial-use restrictions.
4. Error Detection: checks identity consistency, garment fidelity and image defects.

## Status
These are role specifications, **not running autonomous agents**. Runtime orchestration, models and tests are not installed yet.

## Safety
Do not commit passwords, API keys, personal customer photos or unlicensed assets. Keep costs at zero unless explicitly approved.
