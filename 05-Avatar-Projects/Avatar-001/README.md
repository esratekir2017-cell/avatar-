## CEO — Brief
Create one photorealistic adult fashion avatar as a consistent base for later virtual try-on tests. Keep the workflow free-first. Do not purchase credits or publish images without user approval.

## Production — Base avatar prompt
"Full-length studio fashion photograph of a fictional adult woman, natural facial proportions, realistic skin texture, neutral expression, looking at camera, relaxed symmetrical standing pose, arms slightly away from torso, hands visible, simple fitted neutral beige outfit, plain light gray studio backdrop, soft diffused even lighting, 50mm lens look, sharp garment edges, head and feet fully in frame, photorealistic, no text, no logos."

Negative guidance: distorted fingers, extra limbs, cropped feet, asymmetrical eyes, plastic skin, logos, text, heavy filters.

Suggested ratio: 3:4. Save the selected base image and its generation settings for consistency.

## Security — Initial review
- Use a fictional adult avatar, not a real person's likeness without consent.
- Do not upload private customer photos, secrets or API keys.
- Check image model and try-on model licenses separately before commercial use.
- Free-tier availability and limits must be checked in the chosen service before use.

## Error Detection — Acceptance checklist
- Face and eye symmetry plausible
- Five fingers on each visible hand; no extra limbs
- Entire body, head and feet visible
- Neutral clothing and clear silhouette suitable for virtual try-on
- No artifacts, watermarks, embedded text or accidental logos
- Retain seed/reference/settings where supported
